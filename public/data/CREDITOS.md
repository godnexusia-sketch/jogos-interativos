# Créditos dos dados

- `dict.json`: palavras comuns de [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (Hermit Dave, CC BY-SA 4.0, a partir do OpenSubtitles) cruzadas com o dicionário pt_BR do [LibreOffice/VERO](https://github.com/LibreOffice/dictionaries) (LGPL/MPL).
- `drawings.json`: desenhos do [Quick, Draw! Dataset](https://github.com/googlecreativelab/quickdraw-dataset) do Google (CC BY 4.0).
- `countries.json`: [world-countries](https://github.com/mledoze/countries) (ODbL).
- Bandeiras: [flagcdn.com](https://flagcdn.com). Fotos das cidades: Wikipédia/Wikimedia Commons.
- Perguntas, frases e listas em português: escritas para este projeto.


## Personagens 3D
